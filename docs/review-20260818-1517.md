## TodoEntity.java — coverage 40% (❌)

### 🔴 High

- **PK 필드명이 `id`** — 표준은 `Long idx`. `id`는 PK가 아니라 로그인 ID·주문번호 같은
  **비즈니스 식별자 전용**이다.
  - 표준: `07_ENTITY_GUIDE.md` — "ID 전략"
  ```java
  @Id
  @GeneratedValue(strategy = GenerationType.IDENTITY)
  private Long idx;
  ```
- **클래스명 `TodoEntity`** — Entity 접미사 금지. 도메인명 단수 `Todo`.
  - 표준: `03_NAMING_CONVENTIONS.md` — 클래스 표
- **Auditing 컬럼명 불일치** — `createdDate`/`modifiedDate` (DB `created_date`/`modified_date`).
  표준은 `registerDate`/`modifyDate` (DB `register_date`/`modify_date`).
  - 표준: `07_ENTITY_GUIDE.md` — 규칙 3
- **`@Table(name = ...)` 누락** — 테이블명이 클래스명에서 파생돼 `todo_entity`가 됐다.
  `07`과 레퍼런스 구현 기준 **단수 `todo`**.
  - 표준: `07_ENTITY_GUIDE.md` — 규칙 8

### 🟡 Medium

- `@Setter` 없음 — MapStruct `updateEntity(@MappingTarget)`가 setter를 요구한다.
- `@NoArgsConstructor`가 **public** — `access = AccessLevel.PROTECTED` 필요 (외부 인스턴스화 차단).
- `@AllArgsConstructor(access = PRIVATE)` + `@Builder` 없음 — 대신 수동 생성자 사용 중.
- `@Column`에 `length` 미명시.

### 🟢 Low

- 도메인 메서드 `update(...)`가 null 병합 로직을 직접 수행 — MapStruct
  `@BeanMapping(NullValuePropertyMappingStrategy.IGNORE)`가 대체할 책임.

### ✅ 통과

- `jakarta.persistence.*` 사용, `@EntityListeners(AuditingEntityListener.class)`,
  `@CreatedDate`/`@LastModifiedDate`, `@GeneratedValue(IDENTITY)`.
